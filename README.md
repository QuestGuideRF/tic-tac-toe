# Крестики-нолики

Простая игра "Крестики-нолики", реализованная на HTML, CSS и JavaScript.

## Описание

Классическая игра "Крестики-нолики" для двух игроков на одном устройстве. Игроки по очереди ставят X и O на игровом поле размером 3x3. Побеждает тот, кто первым выстроит три своих символа в ряд (по горизонтали, вертикали или диагонали).

## Функциональность

- Игровое поле 3x3
- Поочередные ходы игроков X и O
- Автоматическое определение победителя
- Определение ничьей
- Возможность перезапустить игру

## Как играть

1. Откройте файл `index.html` в любом веб-браузере
2. Первым ходит игрок X, затем O
3. Для хода нажмите на пустую клетку на игровом поле
4. Игра автоматически определит победителя или ничью
5. Для начала новой игры нажмите кнопку "Начать заново"

## Технологии

- HTML5
- CSS3
- JavaScript (ES6)

## Структура проекта

- `index.html` - основная структура игры
- `style.css` - стили для игры
- `script.js` - логика игры
